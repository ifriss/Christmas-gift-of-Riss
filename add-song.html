← Về cây thông

Dùng tài khoản đã đăng ký trên trang cây thông. Chỉ tài khoản quản trị (huy hiệu DEV) mới vào được. Mật khẩu của tài khoản cũng là chìa khóa giải mã token GitHub đã lưu trong repo.

⚙️ Kết nối GitHub

Đăng xuất

🔑 Cập nhật token GitHub (lưu mã hóa vào repo)

Token được mã hóa bằng chính mật khẩu tài khoản bạn vừa đăng nhập (AES-256, PBKDF2) rồi lưu thành config.enc.json trong repo. Nếu sau này bạn đổi mật khẩu tài khoản, hãy vào đây dán lại token để mã hóa lại bằng mật khẩu mới.

🎵 Thêm bài nhạc YouTube mới

Dán link YouTube đầy đủ hoặc mã ID 11 ký tự, tool sẽ tự trích xuất mã và cập nhật thẳng vào index.html.
